## 💰 نماذج الأعمال

### الخطط المتاحة:

#### 1. الأساسية (مجاناً)
- 5 موظفين
- 500 دقيقة/شهر
- **هدفها**: جذب الشركات الصغيرة

#### 2. الاحترافية ($99/شهر)
- 20 موظف
- 2000 دقيقة/شهر
- **هدفها**: الشركات المتوسطة

#### 3. المؤسسات (مخصص)
- غير محدود
- **هدفها**: الشركات الكبيرة

### 💵 توقعات الدخل:

مع **50 شركة**:
- 30 شركة على الخطة المجانية = $0
- 15 شركة على الاحترافية = $1,485/شهر
- 5 شركات على المؤسسات بمتوسط $500 = $2,500/شهر

**إجمالي:** $3,985/شهر ($47,820/سنة)

## 🔗 API Documentation

### Register Company
```http
POST /api/companies/register
Content-Type: application/json

{
  "companyName": "شركة التقنية",
  "commercialNumber": "1234567890",
  "username": "admin",
  "password": "pass123",
  "selectedPlan": "free"
}
```

### Login
```http
POST /api/companies/login
Content-Type: application/json

{
  "username": "admin",
  "password": "pass123"
}
```

### Get All Companies
```http
GET /api/companies
```

### Update Company
```http
PUT /api/companies/:id
Content-Type: application/json

{
  "companyName": "الاسم الجديد"
}
```
