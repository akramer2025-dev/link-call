## 🎛️ تخصيص الحماية (اختياري)

### إذا أردت تعديل إعدادات الحماية:

افتح `protection.js` وابحث عن:
```javascript
const PROTECTION_CONFIG = {
    disableDevTools: true,      // منع DevTools (موصى به)
    disableRightClick: true,    // منع النقر اليمين (موصى به)
    disableTextSelection: true, // منع تحديد النص (موصى به)
    disableConsole: true,       // تعطيل Console (موصى به)
    detectDebugger: true,       // كشف Debugger (موصى به)
    protectCode: true,          // حماية الكود (موصى به)
    watermark: true,            // علامة مائية (موصى به)
    antiCopy: true              // منع النسخ (موصى به)
};
```

**ملاحظة**: غيّر `true` إلى `false` لتعطيل أي ميزة (غير موصى به).

## 🔧 تخصيص Rate Limiting

في `server.js`، ابحث عن:
```javascript
app.use(rateLimiter(200, 60000)); // 200 طلب في الدقيقة
```

**لتغيير الحد:**
- الرقم الأول (200) = عدد الطلبات المسموحة
- الرقم الثاني (60000) = الفترة الزمنية بالميلي ثانية (60000 = دقيقة واحدة)

**مثال**: للسماح ب 500 طلب كل دقيقتين:
```javascript
app.use(rateLimiter(500, 120000));
```

## 🆘 حل المشاكل الشائعة

### مشكلة: "المستخدمون الشرعيون يُحظرون"
**الحل**: زد حد Rate Limiting:
```javascript
app.use(rateLimiter(500, 60000)); // بدلاً من 200
```

### مشكلة: "أحتاج فتح DevTools للتطوير"
**الحل**: عطّل الحماية مؤقتاً في `protection.js`:
```javascript
const PROTECTION_CONFIG = {
    disableDevTools: false, // عطّل فقط أثناء التطوير
    // ... باقي الإعدادات
};
```
⚠️ **تذكّر**: أعد تفعيلها قبل النشر!

### مشكلة: "الحماية لا تعمل"
**تحقق من**:
1. هل `protection.js` موجود في المجلد الرئيسي؟
2. هل تم إضافة السكريبت في HTML؟
3. هل هناك أخطاء في Console المتصفح؟

## 🔍 اختبار الحماية

### اختبار سريع (دقيقة واحدة):

2. اضغط F12
3. إذا ظهرت رسالة حظر = ✅ الحماية تعمل!

3. حاول نسخ النص

5. إذا كلها محظورة = ✅ الحماية قوية!

- Selenium WebDriver
- Puppeteer

- إذا كلها محظورة = ✅ الحماية ممتازة!
